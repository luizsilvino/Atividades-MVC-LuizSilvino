## Objetivo

Desenvolver aplicações Web utilizando ASP.NET Core MVC, aplicando Model, View e Controller,
Views Razor, rotas, regras de negócio e dados mantidos em memória.

## Como executar

1. Abra a pasta do exercício desejado.
2. Dê dois cliques no arquivo `.csproj` para abrir no Visual Studio.
3. Aguarde o carregamento do projeto.
4. Execute pelo botão HTTPS/Executar.
5. Teste os links e páginas da aplicação.
